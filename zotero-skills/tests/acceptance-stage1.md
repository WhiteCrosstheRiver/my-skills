# 第一阶段验收 · 2026-09-23

环境：Windows、Python 3.13、Zotero 10.0.3、Zotero Agent 2.2.2。

- 实际检索 Semantic Scholar、Crossref、arXiv，并扩展引文；185 条候选中按方法覆盖选择 10 篇机器学习原子势论文。
- 实际入库并回读 10 篇、10 篇可读 PDF、10 份 Markdown 附件及完整子便条；157 条带定位的证据声明通过验证，并人工核对代表性参数与表文冲突。
- 每篇再次发布均复用相同便条和 Markdown key；已有人工笔记全文未变。
- 16 项测试通过，含真实 Zotero 合成条目的 PDF 获取失败、元数据保留、提交后中断续跑、人工修改保留；大批量分页单测覆盖 1201 条和 151 条。
- 真实错误令牌返回 HTTP 401；中文路径、中文正文、HTML 表格和代码块、429 重试及证据不足路径已测。

边界：这是有界方法样本，不宣称领域穷尽。部分 PDF 为预印本；缺失补充材料、未运行论文代码、历史仓库与当前版本差异均在各篇笔记披露。验证器检查片段存在，语义仍需要阅读者独立审查。修复首次发布中的尾随换行差异后，重复发布不再新增便条；开发过程留下的历史便条按保全原则保留。

论文、个人 key、完整证据与运行日志只保存在本机私有输出目录，不进入仓库。
