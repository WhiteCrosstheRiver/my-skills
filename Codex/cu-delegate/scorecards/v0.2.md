# v0.2 experimental：已有桌面会话交接

日期：2026-10-04，Asia/Shanghai。上一版浏览器实验见 [v0.1.md](v0.1.md)。

## 改动

桌面任务使用已有且获明确授权的 ZCode Desktop 主会话。Codex 只交接任务书、
读取该会话的回复并验收；目标应用的原生无障碍观察属于 ZCode worker。
独立 CLI 没有桌面主会话的 live host/broker/helper 环境，因此不再作为桌面入口。
`desktop_retry.py` 不包含在交付包里，也不是重试路径。

状态依次是 `not_started` → `awaiting_report` → `report_imported`。
每次任务使用新 ID。准备文件和取回已结束进程输出的短耗时不能冒充执行时间。
同一次交接不能重复发送；未经发送的报告、旧 ID 报告、重复导入均被拒绝。
待交接命令退出码 3；`--doctor` 也不会启动 ZCode CLI。

Codex 没有替代 ZCode 对 Materials Studio 进行第二次读取。
