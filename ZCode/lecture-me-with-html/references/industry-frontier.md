# Industry & Frontier Policy — 落地链条与前沿

## Science → Engineering → Industry 固定模块

构造五级链条,每级至少一个具体名词:

```
基本思想(页内已学的结构)
→ 科学用途(哪个学科用它回答什么问题)
→ 工程方法(数值化:BEM / 稀疏逆 / 递归 / 蒙特卡洛…)
→ 软件与器件(TCAD、QuantumATK、COMSOL、HFSS… 官方文档为证)
→ 产业应用(哪个行业、哪类产品、解决什么良率/性能问题)
```

禁语:"广泛应用于工业""在工程中很重要"。写不出具体链条 = 该模块不达标,
要么检索到具体证据,要么砍掉模块并在 dossier 说明。

## Frontier(活跃主题)

- 检索近三年(以当前年份倒推)review / emerging / open problems / ML 连接。
- 经典结论与最新研究**分区陈述**,页面标注年份。
- 预印本身份明示(arXiv ≠ 已刊)。
- frontier 只描述与主线概念**直接相关**的进展;无关热点不凑数。

## 常见产业锚点(按主题选,不机械全搜)

弹性/应力:TCAD 工艺仿真、位错工程、BEM 求解器
量子输运:NEGF、QuantumATK/Synopsys、量子点器件
电磁:HFSS/CST 的积分方程内核
声学:噪声辐射 BEM
热:傅里叶核、散热设计
金融/ML:核方法、神经算子(如相关)
